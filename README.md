
# Clínica Veterinária 🐾

Aplicativo desenvolvido em Flutter para gerenciamento de pacientes de uma clínica veterinária.

## Funcionalidades

- Cadastro de pacientes.
- Listagem de pacientes cadastrados.
- Edição dos dados dos pacientes.
- Exclusão de pacientes com confirmação.
- Validação dos campos obrigatórios.

## Dados do paciente

Cada paciente possui os seguintes campos:

- Nome do animal
- Raça
- Nome do responsável

## Tecnologias utilizadas

- Flutter
- Dart
- Material Design 3

## Armazenamento

Os dados são armazenados em uma lista em memória durante a execução do aplicativo. Não há integração com banco de dados.

## Como executar

1. Instale o Flutter.
2. Clone este repositório:

```bash
git clone https://github.com/MuriloLAcerda62/clinica-veterinaria.git
```

3. Entre na pasta:

```bash
cd clinica-veterinaria
```

4. Instale as dependências:

```bash
flutter pub get
```

5. Execute o aplicativo:

```bash
flutter run
```
